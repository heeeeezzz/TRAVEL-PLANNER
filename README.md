# TRAVEL PLANNER

여행 일정·이동시간·교통편·숙소·바우처·경비·준비물을 한곳에서 관리하는 개인용 여행 플래너.

## 쓰는 법
- 사이트: `https://heeeeezzz.github.io/TRAVEL-PLANNER/` (GitHub Pages 켠 뒤)
- 첫 화면에서 **＋ 새 여행** → 장소 추가 → 일정 짜기
- ⚙️ 설정에 구글 API 키를 넣으면 구글 지도(한국어)와 한글 장소 검색을 써요. 키가 없으면 무료 지도(OpenFreeMap)와 무료 검색(Photon)으로 동작해요.

## 데이터
- 여행 데이터와 바우처 파일은 **각자 브라우저에만** 저장돼요 (localStorage / IndexedDB). 이 저장소에는 올라가지 않아요.
- 다른 기기로 옮길 땐 여행 카드 ⋯ → 내보내기 → 다른 기기에서 불러오기.
- API 키도 브라우저에만 저장돼요. 키는 구글 클라우드에서 `https://heeeeezzz.github.io/*` 에서만 쓰이도록 제한해 두세요.

## 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀 |
| `style.css` | 스타일 |
| `js/core.js` | 저장소, 일정 계산(이동·교통편·숙소·짐 배송·영업시간), 최적 순서, 경비 |
| `js/maps.js` | 지도(구글 / 무료) · 장소 검색 · 도보 경로(OSRM) |
| `js/planner.js` | 여행 하나의 플래너 화면(일정·장소·교통편·숙소·바우처·경비·준비물·설정) |
| `js/home.js` | 여행 목록 첫 화면, 만들기·복제·삭제·내보내기, 화면 전환 |

## 참고
- 일본 대중교통 소요시간은 구글 API가 제공하지 않아서 거리 기반 추정치 + 직접 입력 + 구글맵 링크로 처리해요.
- 추정식: 15분 + 직선거리 × 1.3 ÷ 시속 30km (`js/core.js`의 `estTransit`).
